# AI 智能订舱录单系统

> 菜鸟国际空运核心提效项目 — 用 AI Agent 替代人工重复录入，实现航空货运订舱与录单的端到端自动化。

---

## 项目简介

AI 智能订舱录单系统是菜鸟国际空运业务的核心自动化解决方案。系统将传统的「运营人工读文件 → 手动录系统」模式，升级为「AI 解析文件 → 自动提交系统 → 人审异常」的智能工作流，每条主单节省约 **5 分钟**操作时间。

项目自 2025 年 12 月立项，历经三个 Phase、10 个月迭代，已完成**订舱、主单录单、分单录单**三项核心能力建设，覆盖 **9 条核心航线**，累计自动化成功处理 **4,418 单**。

## 产品介绍

### 产品定位

主单任务管理是系统的核心操作页面，运营小二通过该页面完成**解析规则配置、文件上传、任务监控、人工确认**全流程操作。系统以主单号（MAWB）为业务主键，串联订舱、主单录入、分单录入三类任务，实现「一次上传、自动识别、串行执行、异常兜底」。

### 核心能力

1. **解析规则管理** — 按航线配置主单/分单的 AI 解析规则，支持提示词模板、字段校验、一键测试，是任务执行的前提。
2. **混合文件批量上传** — 支持 PDF / DOC / DOCX / XLS / XLSX / TXT / CSV 等多格式混传，系统自动识别分类（订舱表 / 主单 / 分单 / 舱单）。
3. **上传历史追踪** — 每批次文件解析进度与结果可视化，实时查看处理状态。
4. **主单任务管理** — 一站式查看订舱 → 主单 → 分单全链路进程，支持五项筛选（主单号 / 状态 / 航线 / 航司 / 时间）。
5. **任务状态实时刷新** — 页面自动轮询刷新（任务管理 6s / 上传历史 9s），支持手动触发执行。
6. **人工确认与异常干预闭环** — 异常任务可驳回、修正后重新发起，系统保留版本记录。

### 文件识别规则

| 文件类型 | 识别依据 |
|----------|----------|
| 订舱表 | 含多主单号清单 / 订舱表关键特征 |
| 主单 | 左上角 = 右上角，同为「3位航司代码-8位主单号」格式 |
| 分单 | 左上角为主单号格式，右上角为非主单号的分单号 |
| 舱单 | 含 "Manifest" 关键字，表头为主单信息，明细行为 N 条分单 |

### 自动提交与串行调度

上传时可选择开启「自动提交」开关：解析无阻塞异常的任务将自动提交执行；关闭则任务停留在待执行状态，由运营人工发起。分单任务遵循串行规则——主单录入完成后分单才能执行。系统通过幂等键（主单号 + 分单号）自动阻断重复提交。

## 技术架构亮点

- **AI Agent 任务编排**：主子流程调度架构，支持订舱 → 主单 → 分单串行自动路由，账号资源排队机制保障多航线并发稳定。
- **多格式文档解析**：覆盖 PDF / DOC / DOCX / XLS / XLSX / TXT / CSV，基于提示词模板的字段提取与校验，支持按航线配置差异化规则。
- **GUI 自动化录单**：替代人工在 CCSP 等航司系统的界面操作，自动填表、提交、截图留证。
- **异常兜底闭环**：解析异常 → 人工确认 → 驳回修正 → 重新执行，全程版本可追溯。
- **指标看板驱动**：渗透率、成功率、自动化提交率、算法准确率四维指标实时监控，数据驱动持续优化。

## 常见问题 FAQ

**Q：上传文件后没有看到任务创建？**
确认文件格式是否正确，并在上传历史中查看解析状态。文件识别置信度低时会转人工标注。

**Q：分单任务一直显示「待执行」？**
检查主单录入是否已完成（串行规则要求主单先行），以及是否开启了自动提交开关。

**Q：人工确认时发现字段有误？**
点击「驳回」进入异常状态，修正后重新发起执行，系统保留版本记录。

**Q：同一主单号重复上传会怎样？**
系统通过幂等键（主单号 + 分单号）自动阻断，不会产生重复任务。

**Q：如何查看 AI 执行的具体内容？**
在主单任务管理页面点击「AgentZ 任务」按钮，可查看 AI 执行的详细信息和提交截图。
